# Day 4 (2026-10-23): UI day

Goal: `web/live.html` becomes the demo UI: listening modes, favourite-player earcon, "what did I miss", TR/EN app language.
Vanilla JS, no build step. Server change is minimal: the listener can send `set_mode`; cues carry `player_id`; `hello` lists players.

Done when:
- One selector (TR/EN, browser language by default, remembered) switches every UI string and the narration language; all strings live in the `T` dictionary.
- Modes: Audio only (pitch hidden, no clock/meters), Casual, Analyst (meters + event log). The mode is also sent to the Director (silence budget).
- Favourite player: a chime in the ball's pan position when that player touches the ball (max once per 3 s of match time).
- "What did I miss": last 5 narrations listed; the button reads score + last 3 aloud.
- `ruff check . && pytest` pass.

Owner listens and looks (audio and layout need ears and eyes): modes, chime, recap, phone width, screen reader.
